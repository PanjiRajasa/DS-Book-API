# 📚 DS Book API

A legacy backend API for a bookstore application, originally built during my vocational high school (SMK) days and preserved in its original state.

> 💡 **Developer's Note:**  
> This archived repository marks an early milestone in my transition toward modern backend stacks (Node.js, TypeScript, and Serverless Firebase). It is preserved as-is to document my learning curve, architecture choices, and growth over time.

### 🌟 High-Level Overview
* **Bookstore Service:** API endpoints designed for managing bookstore operations and inventory.
* **Firebase Ecosystem:** Integrated with Firestore for database management and Firebase Security Rules.
* **Monorepo / Submodule Setup:** Includes a connected frontend client via Git Submodules (`dsbook-pages`).

### 🛠️ Tech Stack
* **Runtime:** Node.js
* **Language:** TypeScript
* **Database & Cloud:** Firebase (Firestore / Cloud Functions)
* **Configuration:** Express / Custom Routing
